name: レビュー・言語化ワークフロー
description: PR作成後のレビューサイクルでスクラップとIssueを更新する進め方
type: feedback
---

PRマージ前のレビュー作業はこの流れで進める：

1. ユーザーが手動でPR作成（PR文章はユーザーの言語化を拾いながらClaudeが整形）
2. ユーザーがPRをレビュー
3. スクラップの言語化チェックリストを１項目ずつ口頭で潰していく
4. 会話の中で理解が深まった内容・修正された理解をスクラップに追記してコミット
5. 実装詳細（SDKのインストール方法・セキュリティ注意事項など）はIssueに追記する
6. マージ

**PR文章の作り方：** ユーザーの言語化を待ってから整形する。Claudeから先に文章を出さない。
「これについては？」と問いかけて引き出し、補足・誤り修正をしながら誘導する。

**Why:** スクラップは「自分の言葉で説明できるか」の出口。Issueは実装時の手がかり。両方をレビュー中に育てていく。

**How to apply:** 言語化チェック中に「ドキュメントに追記したい」という発言が出たら、スクラップかIssueか判断して即反映する。実装詳細はIssue、理解・背景はスクラップ。
