# 設定画面の招待リンク表示・joinページのグループ情報表示

## 何を作ったか

### 1. 設定画面に招待リンクセクションを追加

`auth/line` のレスポンスに `invite_token` を追加し、設定画面でLIFF URL形式の招待リンクを表示。
コピーボタンと「LINEで送る」ボタンを設置。

### 2. joinページにグループ・犬の情報を表示

招待リンクを開いた人が「どこからの招待か」を確認できるよう、
グループ名・犬の名前・生年月日（年齢）を表示。

### 3. `GET /api/v1/groups/preview` エンドポイントを追加

認証不要のエンドポイント。`invite_token` を使ってグループ・犬の情報を返す。
`invite_token` 自体が秘密情報なので認証は不要と判断。

## 設計判断

### なぜ `auth/line` に `invite_token` を含めたか

設定画面はすでに `auth/line` を呼んでいる。別途グループ情報を取るエンドポイントを
追加するより、既存のレスポンスに乗せる方がリクエスト数を減らせる。
グループに所属していない場合は `null` を返す。

### なぜ `preview` エンドポイントは認証不要か

`invite_token` が推測困難なランダム文字列（`SecureRandom.urlsafe_base64(16)`）のため、
それ自体が認証の代わりになる。joinページを開いた段階ではLIFF認証が
まだ完了していない可能性もあり、認証不要にした方がUXが安定する。

### 年齢の計算

誕生月が現在月より後の場合は `years - 1` で調整。
```typescript
const age = months < 0 ? years - 1 : years
```
