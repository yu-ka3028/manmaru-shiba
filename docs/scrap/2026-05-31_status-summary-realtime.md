# ステータスサマリーをリアルタイムデータに切り替え

## 背景・変更内容

タイムライン画面のヘッダー下に表示される 2x2 のステータスサマリー（おしっこ・うんち・散歩・ごはん）が、
ハードコードのダミー値を返す `createDefaultStatusItems()` を使い続けており、
API から取得した実際の記録が反映されていなかった。

## 解決アプローチ

`records` state（APIから取得した `TimelineEntry[]`）を受け取り、
その場で各ステータス値を計算する `buildStatusItems(records)` 関数を追加した。

### 計算ロジック

| 項目 | ロジック |
|---|---|
| おしっこ | 最新の `pee` 記録からの経過時間（分/時間）。なければ「なし」 |
| うんち | 最新の `poop` 記録からの経過時間。4時間超で `isWarning: true` |
| 散歩 | 今日の `walk_short` + `walk_long` の合計回数。0 回なら「なし」 |
| ごはん | 最新の `meal` 記録の時刻（HH:MM）。なければ「なし」 |

### 経過時間のフォーマット

- 60分未満 → `X分前`
- 60分以上 → `X時間前`
