# お手入れ記録管理

**日付：** 2026-09-21
**テーマ：** アプリ側でのお手入れ履歴管理

## 決定事項まとめ

- 既存の `care_records` とは分離し、`grooming_records` を追加する。
- お手入れ種別は爪切り、シャンプー、ブラッシング、その他とする。
- お手入れの実施日時を登録し、履歴を降順で表示する。
- LIFFへの同期、アラート、通知、予定管理は対象外とする。
- 登録・一覧表示を初期スコープとし、編集・削除は対象外とする。
- トップページのNOW表示直下からお手入れ記録ページへ遷移できるようにする。
- ローカル動作確認では、development環境に限りLIFF認証をモックする。本番のLINE認証経路は変更しない。

## テスト方針

- Rails標準のMinitestを継続利用する。
- APIの認証、所属グループ境界、入力バリデーション、ページングをテストする。
- RSpec導入はCI基盤と既存テストの安定後に再判断する。
